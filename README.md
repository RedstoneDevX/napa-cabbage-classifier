# 白菜识别模型 · Napa Cabbage Classifier

用一个小模型判断：**这张图里的是不是大白菜（napa cabbage）**。

- 主干：`MobileNetV3-Small`（ImageNet 预训练、冻结特征）
- 分类头：线性层（2 类），权重仅 **577 个 fp16 数**（1.5 KB）
- 侧链：用 `CLIP ViT-B/32` 零样本给抓来的网图**自动查错标**，再人工核对
- 硬件：纯 CPU 可跑，单张推理约 30 ms

## 效果

验证集（训练时未见过，95 张）上的结果：

| 指标 | 数值 |
|---|---|
| 整体准确率 | **97.9%** |
| 白菜 召回率 | 86.7% |
| 白菜 精确率 | 100% |
| 不是白菜 精确率 / 召回率 | 97.6% / 100% |

混淆矩阵（行=真实，列=预测）：

```
            预测白菜   预测非白菜
真实白菜       13          2
真实非白菜      0         80
```

## 快速开始

```bash
pip install -r requirements.txt
python3 predict.py 图片.jpg        # 单张
python3 predict.py 某个文件夹/      # 批量
```

输出：

```
known_cabbage.jpg  ->  白菜  (置信度 100.0%)
known_car.jpg      ->  不是白菜  (置信度 99.9%)
```

首次运行会从 torchvision 官方地址下载 MobileNetV3-Small 的主干权重（约 10 MB）。分类头权重已经在本仓库里（`head_b64.txt`）。

## 实测样例

| # | 图片内容 | 判定 | 置信度 |
|---|---|---|---|
| 1 | 圆白菜（卷心菜） | 不是白菜 | 77.3% |
| 2 | 大白菜商品图 | **白菜** | 100.0% |
| 3 | 红绿辣椒 | 不是白菜 | 99.8% |
| 4 | 长得像白菜的异星植物（AI 生成） | 不是白菜 | 91.2% |
| 5 | 手机实拍、塑料袋里的大白菜 | **白菜** | 99.0% |

置信度分布很有意思：**越像白菜的东西给分越保守**（圆白菜 77%），完全不相干的东西直接 99%+。

## 数据集怎么做的

1. `crawl.py`：按 50+ 关键词从 Bing 图片搜索抓了约 2600 张候选图（白菜类 + 各类"不是白菜"：卷心菜、生菜、西兰花、番茄、水果、汽车、猫狗、家具……）
2. 过滤：最小边 <128px、损坏图、重复图（感知哈希去重）
3. `clean_labels.py`：用 CLIP 逐张判断"这张到底是什么"，踢掉混进来的女明星、电路海报、说明书、以及"非白菜"里其实是白菜的图
4. 人工核对：把剩下的白菜图拼成带编号的检查图，人工删掉错标（人物、内衣、花、菜品等）
5. 最终：**白菜 75 张 + 不是白菜 397 张**（数据集本身不入库，只有流程脚本）

## 训练

```bash
tree -L 1 data_clean
# data_clean/baicai/        75 张
# data_clean/not_baicai/   397 张
python3 train.py     # 提取特征 -> 逻辑回归 -> 导出 head_b64.txt / cabbage_model.pt / metrics.json
```

## 局限（重要）

- 正样本只有 75 张，偏少；补充真实拍照能明显提升。
- 认的是"大白菜 / 娃娃菜"这种**瘦长、白帮绿叶**的形态：**小白菜、上海青、泡菜、切碎的菜叶**容易判错。
- 圆白菜（卷心菜）被特意当作"难负样本"，能分开，但没见过的近似品种可能失手。
- 训练图多为网络商品图，手机实拍若光线/角度差别大，置信度会下降。
