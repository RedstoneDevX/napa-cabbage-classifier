# 蔬菜识别模型 · Vegetable Classifier

用一个小模型判断图片里是：**白菜 / 花菜 / 青椒 / 其他**。

- 主干：`MobileNetV3-Small`（ImageNet 预训练、冻结特征）
- 分类头：`4 × 576` 线性权重，**int8 量化**后只有 3 KB（存在 `weights/part0..3.txt`）
- 侧链：用 `CLIP ViT-B/32` 零样本给抓来的网图**自动查错标**，再人工核对
- 硬件：纯 CPU 可跑，单张推理约 30 ms

## 效果

验证集（1/5 holdout，训练时未见过，135 张，整体 **91.9%**）：

| 类别 | 正确 / 总数 | 准确率 |
|---|---|---|
| 白菜 | 12 / 14 | 85.7% |
| 花菜 | 9 / 9 | 100% |
| 青椒 | 11 / 14 | 78.6% |
| 其他 | 92 / 98 | 93.9% |

混淆矩阵（行 = 真实，列 = 预测）：

```
        白菜  花菜  青椒  其他
白菜     12    0    0    2
花菜      0    9    0    0
青椒      0    1   11    2
其他      3    0    3   92
```

> 注：这一版把“卷心菜、生菜、菠菜、小白菜”等 **131 张叶菜难负样本**加进了“其他”，
> 所以整体准确率比纯白菜版（97.9%）低，但**泛化更诚实**：现在圆白菜能正确判成“其他”，
> 而不是被当成白菜。

## 快速开始

```bash
pip install -r requirements.txt
python3 predict.py 图片.jpg        # 单张
python3 predict.py 某个文件夹/      # 批量
```

输出：

```
01.jpg  ->  白菜  (置信度 97.9%)
02.jpg  ->  花菜  (置信度 100.0%)
03.jpg  ->  青椒  (置信度 99.0%)
04.jpg  ->  其他  (置信度 99.2%)
```

首次运行会从 torchvision 官方地址下载 MobileNetV3-Small 的主干权重（约 10 MB），分类头权重已在本仓库。

## 数据集

| 类别 | 数量 | 说明 |
|---|---|---|
| 白菜 | 70 | 大白菜、娃娃菜、黄心白菜 |
| 花菜 | 44 | 白花菜（白花椰菜）；西兰花归“其他” |
| 青椒 | 66 | 绿色灯笼椒、尖椒、杭椒、线椒 |
| 其他 | 488 | 卷心菜、生菜、菠菜、小白菜、西兰花、番茄、土豆、水果、汽车、家具…… |

数据管线的四道关：

1. `crawl.py` / `crawl_veg.py`：Bing 图片搜索批量抓候选图（约 3000 张）
2. 过滤：最小边 <128px、损坏、重复图（感知哈希去重）
3. `clean_labels.py`：CLIP 逐张判断“这张到底是什么”，踢掉混进来的明星照、电路海报、说明书等
4. **颜色 + 细分提示词**：花菜要求“白色区域明显（排除西兰花）”，青椒要求“以绿色为主（排除红椒/红辣椒）”
5. 人工核对：拼成带编号的检查图，人工删错标

## 训练

```bash
# 目录结构
tree -L 1 data_clean veg_clean
# data_clean/baicai/   70    data_clean/not_baicai/  488（白名单见 clean_list.json）
# veg_clean/huacai/    44    veg_clean/qingjiao/      66
python3 train.py   # 特征 -> 逻辑回归 -> int8 量化 -> 分类头权重
```

## 仓库结构

```
.
├── predict.py          # 推理（读 weights/ 下的分片权重）
├── train.py            # 训练（特征提取 + 逻辑回归 + int8 量化）
├── crawl.py            # 抓白菜 / 非白菜图片
├── crawl_veg.py        # 抓花菜 / 青椒图片
├── clean_labels.py     # 用 CLIP 零样本自动查错标
├── requirements.txt
└── weights/
    ├── part0.txt       # 分类头 int8 权重分片（4 片拼起来才是完整 base64）
    ├── part1.txt
    ├── part2.txt
    └── part3.txt
```

分类头只有 3 KB，所以直接以 base64 文本存进仓库；主干 MobileNetV3-Small 在首次运行时由 torchvision 自动下载。

## 局限（重要）

- 样本量整体偏少（几百张），真实拍照与网图风格差异大时，置信度会捣蛋。
- “花菜”指 **白花菜**：绿色的西兰花会被判成“其他”。
- “青椒”包含尖椒/杭椒等绿色辣椒；红椒、黄椒不在这一类。
- 易错点：叶子特写、小白菜、娃娃菜容易在“白菜 / 其他”之间摆动。
- 批量场景建议把置信度过低的图挑出来人工再看一眼。
